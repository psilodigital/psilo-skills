# grill-me

Stress-test any plan or design through relentless interviewing. Claude walks down each branch of the decision tree, resolves dependencies between decisions, and provides its own recommended answer for each question.

## Usage

```
/grill-me
```

Then describe your plan, design, or idea. Claude will interview you one question at a time until every branch is resolved.

## When to use

- Before committing to an architecture or technical approach
- Stress-testing a product or feature plan
- Surfacing blind spots in any decision you're about to make
